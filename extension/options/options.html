Compass Economic Calendar

Settings apply to the popup and to advance notifications.

Display

Applies to both the popup list and notifications.

Notifications

Comma separated, up to four. Applies to timed events.

Local hour, 0–23. All-day entries such as futures roll dates have no start time, so they get one nudge on the day instead.

Calendar subscriptions

The same data as a subscribable feed, for Google Calendar, Apple Calendar or Outlook. Desktop Google Calendar: Other calendars → + → From URL.

  • Full calendar (.ics)
  • High impact only (.ics)
  • Raw JSON feed

Hide event types

Unchecked types are removed from the popup and never notify. Counts come from the cached feed.
